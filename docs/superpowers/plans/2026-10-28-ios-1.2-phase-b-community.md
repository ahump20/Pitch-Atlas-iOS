# Phase B — Community correctness, four states, accessibility (Plan 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** the app's community layer reads and writes exactly what the web does, says the web's words when it can't, and every data surface carries its four states.

**Architecture:** one `CommunityTopic` value builds every discussion key; `CommunityPanel` takes a topic instead of a pitch slug (field notes only on specimens). Reads go through the server's moderated projections. Copy is lifted from web main 47e21e6 (`lib/community.ts`, `lib/discussion.ts`, `FieldNotes.tsx`, `DiscussionForum.tsx`).

**Tech stack:** SwiftUI iOS 17, supabase-swift, XCTest.

**Spec:** `docs/superpowers/specs/2026-10-05-ios-web-parity-design.md` (+ addendum 2026-10-27); release plan `docs/superpowers/plans/2026-10-27-ios-1.2-parity-release.md` Phase B; master plan §7.

## Global constraints
- Reads never mint a session; `ensureSessionForWrite()` stays the only mint site.
- No mock rows, no seeded posts. Server text is shown only where the web shows it (the tagged trigger messages); other server detail never reaches a reader.
- Supabase stays; column-scoped insert grants hold (`testInsertPayloadsStayInsideColumnScopedInsertGrants`).
- Production data is read-only from here: no migrations, no row edits.

## Verified before planning (2026-10-28)
- Production `list_public_field_notes(p_pitch_slug)` answers 200 for an anonymous caller.
- No public `discussion_posts` row carries the app's old `pitch:<slug>` key, so moving specimens to the bare slug strands nothing visible.

## Tasks

### B1 — `CommunityTopic`
- Create `PitchAtlas/Core/Supabase/CommunityTopic.swift`: `enum CommunityTopic: Hashable { case specimen(slug:), repertoire(id:), lost(slug:), learn(slug:), softball(slug:) }`, `var key: String` (bare slug; `repertoire:<id>`; `lost:<slug>`; `learn:<slug>`; `softball:<slug>`), `var allowsFieldNotes: Bool` (specimen only), `static func learnWing(_ wing:) -> CommunityTopic?` (nil when the wing is boundary-only).
- `CommunityPanel(topic:topicName:provenanceNote:safetyNote:)`; the segmented Field Notes / Discussion control shows only when the topic allows notes. Field-note slug comes from the topic.
- Tests `CommunityTopicTests`: every key format; notes only on specimens; boundary-only wings get no topic.

### B2 — Reads and words
- `CommunityService.fieldNotes(pitchSlug:)` calls `rpc("list_public_field_notes", params: FieldNotesParams(pitchSlug:))`.
- Lossy list decode for notes and posts: one row that won't decode is dropped, never the whole list; `authorID` optional (a deleted author's row stays readable; Block hides without an author).
- After filing a note: "Sent for review ✓ · it stays private until approved."
- `userMessage(for:)`: tagged trigger messages show the server's own sentence after the tag (`content_blocked:`, `rate_limit:`, `media_blocked:`, `too_deep:`, `invalid_parent:`), the web's fallbacks when the tail is empty; the `contains("banned")` match goes.
- Failure states: "Couldn't load the field notes." / "Could not load the discussion." + "The server didn't answer." + Try again; no server text.
- Empty field notes: "No field notes filed yet" / "No field notes filed yet for this pitch. The first one starts the drawer. Add how you throw it above."
- Tests: RPC params encode `p_pitch_slug`; lossy decode keeps good rows; message mapping per tag; outage copy never contains the error text.

### B3 — Delete your own post
- `CommunityService.deletePost(id:)`: the web's guard — replies by another living contributor block it with "That post has replies from other contributors, so it cannot be deleted."; own media paths removed best-effort after the row delete.
- Own posts get "Delete post" (confirmation dialog) in the post menu.
- Tests: the guard's decision function over reply author ids (nil authors don't block).

### B4 — Four states
- The media tile's bare spinner becomes a source-tagged skeleton tile; every community and content surface checked for loading / empty / error-with-reason / populated.

### B5 — Copy fixes
