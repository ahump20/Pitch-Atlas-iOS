# iOS 1.2 Phase D — The Site's New Sections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything pitch-atlas.com added since the app's last release is in the app natively — the compare tray and its one-pitch bench, Shape Lab, the Shape map, the ten hidden notes, the softball wing, the media suggestion form, and the Flight Lab schematic — each checked against the same page at 440pt.

**Architecture:** Each section is a native SwiftUI screen on the Phase C page kit (`SectionHero`, `PageSection`, `SectionKick`, `SectionTitle`, `NumberedRow`, `Plate`, `SiteFooter`). Pure logic the site keeps in `src/lib` (sandbox, slowpitch, external-content validation, the tray's selection rules, where a hidden note lives) is ported to small Swift value types and pinned by XCTest against the web's own tests and values. Content is generated by `tools/generate-content`; the one new export is the Flight Lab data. Every new screen is a `pitchatlas://` route with a router test, a tour stop and a site-capture entry.

**Tech Stack:** SwiftUI (iOS 17.0 floor), XcodeGen, XCTest/XCUITest, Supabase Swift (the suggestion insert only), GitHub Actions screenshots.

**Spec:** `docs/superpowers/specs/2026-10-05-ios-web-parity-design.md` with its 2026-10-27 addendum (decision 2: which new web features ship and how); release plan `docs/superpowers/plans/2026-10-27-ios-1.2-parity-release.md` (Phase D). Inventory of the site's features (files, strings, tests, data): this plan's ledger, first section.

## Global Constraints

- Every Phase C constraint holds (`docs/superpowers/plans/2026-10-28-ios-1.2-phase-c-screens.md`, Global Constraints): iOS 17.0, `SWIFT_VERSION "5.0"`, no color literals outside `PitchAtlas/Core/Theme/`, XcodeGen only, generated content only, no invented numbers or freshness, four states on every data surface, 44pt taps, Dynamic Type, VoiceOver, Reduce Motion, "sourced, not corrected" nowhere, no outside brand, Account and Safety one tap from Atlas, `type(scope): description` commits with the session lines.
- Copy the site hard-codes is ported verbatim with the web file named in a comment, checked with `scratchpad/verbatim.py <swift> <tsx…>`; any change is a ledgered ruling.
- Every new route (`softball`, `softball/fastpitch`, `softball/slowpitch`, `softball/pitch/<slug>`, `softball/craftsmen/<slug>`, `softball/flight-lab`, `movement-map`, `sandbox`) gets a `DeepLinkRouterTests` line, a `ScreenshotTourUITests` stop and a `scripts/capture-web.mjs` entry; a bad slug lands on the hub or list it would have lived in.
- The Shape map's family colors (#BF5700, #5FE0EA, #D8CFBB) and any new ink live in a `Core/Theme/` file.
- Sliders (Shape Lab tilt, Flight Lab tune and batter): 44pt thumbs, a VoiceOver value in words ("3:00 run", "Apex 8.5 feet"), adjustable by VoiceOver increments; Flight Lab's Throw lands on its final frame under Reduce Motion.
- Found hidden notes persist as an id list in `UserDefaults` (`pa-tidbits-found-v1`, the site's key); the found index lists all ten with their locations even when locked; "n of 10" is always completable in the app.
- Field placeholders are verbatim prompts (`TextField("", text:, prompt: Text(verbatim:))`): a titled key parses Markdown and turns a URL or an address into a link (the C9 Account finding). Holo words use `PitchAtlasMaterials.holoType()`, the site's `.rfx-holo` at rest.
- The suggestion form writes to production only on a reader's own tap. No test, screenshot run or local check submits it; tests cover validation and the encoded payload only.
- The C7 ruling that opens `/movement-map` "Keep reading" links on the site reverses when the Shape map lands; the footer's Softball link and the home doors' softball door ("joins later") are wired by the softball task.
- Every task ends with its screenshot pair reviewed and its CI green; the next task starts while those run.

## Review Focus

1. **A deep link with a bad slug into a new section** (`softball/pitch/no-such`, `softball/craftsmen/no-such`, `sandbox?tilt=17`, `sandbox?pitch=no-such`) — lands on the hub, list or default tilt, never a dead push. Pinned in D2, D3, D5.
2. **Every hidden note reachable** — each of the ten ids maps to a screen and element the app ships (including Shape Lab's "Teaching model" and the Index's exact "eephus" search). Pinned in D4.
3. **The suggestion form offline or with no session** — the reason shows, the typed URL and words stay, nothing is half-filed. Pinned in D6.
4. **Flight Lab at the slider extremes** (apex 13 ft, land −30 in, side ±24 in, every rulebook) — the solver converges or the page shows the site's unsolved warning; no NaN reaches a drawing. Pinned in D7.
5. **The compare tray at AX5 Dynamic Type** — the tray wraps and never covers the tab bar or the last row of a page. Pinned in D1 (layout test) and the AX5 shots in Phase E.
